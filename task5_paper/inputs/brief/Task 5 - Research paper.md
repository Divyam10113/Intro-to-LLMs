# Final task: write the research paper

(The instructor's description, saved verbatim from the user's message, 2026-11-21.)

This assignment aims at consolidating the outputs of all the prior assignments to formulate a research paper. The research paper would typically have following sections:

1. Abstract: Once we are done with finalising the rest of the sections, abstract can be written with LLM in the loop by feeding the rest of the paper.
2. Introduction: Introduction typically consists of 2 parts: (i) Background motivation followed by problem definition: The output of the research gap/ limitation extraction from literature followed by problem formulation assignment can be utilised to write this part of the introduction. (ii) Contributions: The output of Ideation assignment can be used to write this part by extracting the main novel contributions of the implemented solution
3. Related works: The output of literature review section with some manual filtering of unrelated papers can be used here. The output should be arranged in a proper hierarchical catalogue (section, subsection hierarchies).
4. Problem Formulation: The output of problem formulation assignment can be fed to LLM to get the mathematical definition of the defined research problem, which can be further manually verified.
5. Methodology: This section can have subsections such as dataset, approach etc. The output of the ideation assignment can be used and appropriately written by avoiding all low-level experimentation and implementation details to write this section. This section should elaborate the high-level solution.
6. Experimentation / results and discussion: The output of codification assignment can be verbalised and presented as the part of this section, with elaboration of the experiments performed.
7. Conclusion: We can take help of the LLM by providing it the rest of the sections and asking what conclusions can be drawn which can be manually verified.

The task is to write the research paper following the above instructions. If the work has some good results and analysis the paper can be submitted to workshops on AI generated papers (optional).
